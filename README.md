# Gate Mushroom Card

Карточка ворот для Home Assistant в стиле [Mushroom](https://github.com/piitaya/lovelace-mushroom):
компактный ряд «иконка + название + статус + кнопка». Поддерживает **откатные**,
**секционные (подъёмные)** и **распашные** ворота.

Состояние отображается **иконкой и текстом одновременно**: иконка и её цвет меняются
по состоянию (закрыто / открыто / открывается / закрывается / остановлено / недоступно),
во время движения иконка пульсирует. Все иконки настраиваются через **визуальный редактор**
карточки (без YAML).

![стиль mushroom](https://img.shields.io/badge/style-mushroom-43a047)

## Возможности

- Типы ворот: откатные, секционные, распашные — влияют на иконки по умолчанию.
- Управление:
  - `cover.*` — штатные `open_cover` / `stop_cover` / `close_cover`, показ позиции в %;
  - `switch.*` — импульсный триггер (например, Zigbee-реле ворот);
  - `button.*` — `button.press`.
- Статус из любого датчика: `binary_sensor` (контакт, `on` = открыто), `sensor`
  (`on/off/open/closed/...`) или `cover`. Датчик можно инвертировать (`on` = закрыто).
- Без датчика карточка оценивает состояние по таймауту движения.
- Импульсная логика как у настоящих ворот: нажатие во время движения = **Стоп**,
  следующее нажатие = **Продолжить**.
- Если датчик не подтвердил положение за таймаут — состояние «Остановлено»
  (например, ворота остановились препятствием или сработала защита).
- Иконки по умолчанию (проверены в MDI):

| Состояние | Откатные | Секционные | Распашные |
|---|---|---|---|
| Закрыто | `mdi:gate` | `mdi:garage` | `mdi:gate` |
| Открыто | `mdi:gate-open` | `mdi:garage-open` | `mdi:gate-open` |
| Открывается | `mdi:gate-arrow-right` | `mdi:garage-open` | `mdi:gate-open` |
| Закрывается | `mdi:gate-arrow-left` | `mdi:garage` | `mdi:gate` |
| Остановлено | `mdi:gate-alert` | `mdi:garage-alert` | `mdi:gate-alert` |
| Недоступно | `mdi:alert-circle` | `mdi:alert-circle` | `mdi:alert-circle` |

## Установка

### Marketplace (встроенный магазин Home Assistant)

Настройки → Marketplace → добавить репозиторий `dmitry-ponamarev/gate-mushroom-card`
(категория «plugin») → установить. Ресурс Lovelace регистрируется автоматически.

### Вручную

1. Скопируйте `gate-mushroom-card.js` в `/config/www/`.
2. Настройки → Панели → ресурсы → добавить `/local/gate-mushroom-card.js` (тип: модуль JavaScript).

## Настройка

Добавьте карточку «Gate Mushroom Card» — откроется визуальный редактор:

- **Сущность управления** — `cover`, `switch` или `button`, которые двигают ворота.
- **Датчик состояния** — необязательно; контакт или другой датчик положения.
- **Тип ворот** — откатные / секционные / распашные (меняет иконки по умолчанию).
- **Вид карточки** — горизонтальный (иконка слева, как обычно) или вертикальный
  (иконка сверху, текст под ней, кнопка на всю ширину — как у Mushroom-карточек).
- **Инвертировать датчик** — если `on` означает «закрыто».
- **Таймаут движения** — сколько ждать подтверждения от датчика (по умолчанию 30 с).
- **Иконки по состояниям** — раскрывающаяся секция с пикером иконок для каждого
  состояния плюс поле «одна иконка для всех состояний».

### Примеры YAML

Импульсное управление с датчиком контакта (Zigbee-реле):

```yaml
type: custom:gate-mushroom-card
entity: switch.yardgate_trigger
status_entity: binary_sensor.yardgate_garage_door_contact
name: Ворота во двор
gate_type: sliding
move_timeout: 30
```

Секционные ворота с позицией:

```yaml
type: custom:gate-mushroom-card
entity: cover.garage_door
name: Гаражные ворота
gate_type: sectional
```

Свои иконки + вертикальный вид:

```yaml
type: custom:gate-mushroom-card
entity: switch.gate_trigger
status_entity: binary_sensor.gate_contact
gate_type: swing
layout: vertical
icon_open: mdi:door-open
icon_closed: mdi:door-closed
icon_opening: mdi:arrow-up-bold
icon_closing: mdi:arrow-down-bold
```

## Поведение и граничные случаи

- **Приоритет иконок**: `icon_<состояние>` → `icon` (одна для всех) → иконки по типу ворот.
- **Датчик — источник истины**: как только датчик сообщил конечное положение,
  карточка показывает его, даже если таймаут ещё не истёк.
- **Перезапуск HA**: при наличии датчика состояние восстановится сразу; без датчика
  карточка начинает с предположения «закрыто» до первого нажатия.
- **Недоступность**: если сущность управления или датчик `unavailable`/`unknown`,
  карточка показывает «Недоступно» и блокирует кнопку. Для `button.*` состояние
  `unknown` до первого нажатия считается нормой.
- **Частично открытые cover**: при позиции 0 < x < 100 кнопка предлагает
  «Открыть» (x < 50) или «Закрыть» (x ≥ 50), позиция показана в статусе.

> ⚠️ Автоматизация ворот не должна быть единственной защитой: оставляйте штатные
> фотоэлементы и реверс привода активными. Карточка только отображает статус и отправляет
> команды — она не управляет безопасностью привода.
